# 灵动岛 DynamicIsland v1.0.4

本次发布交付翻页修复的第一至第四阶段，并包含此前尚未发布的六页界面与材质改造。第五、六阶段延期，完整开发内容与验收标准见 [后续计划](../paging-future-plan.md)。

## 已完成

- 滚轮按标准刻度累计、保留余数，修复反向抵消和单事件多刻度丢失。
- 滚轮改为连续追赶最新目标，连滚/反向保留速度；点击分页仍逐页播放，两种输入接管时清理旧请求。
- 六页按各自尺寸固定排版并顶部锚定，减少岛体伸缩造成的内容漂移和重排；媒体页头、正文和封面随整页移动。
- 通知与剪贴板合为动态页，增加通知保留设置；包含四档材质、指针反馈、强调色 bloom 与字号统一等界面改进。

## 验证与实际边界

- 三格输入后的页面逻辑尾延迟由约 659ms 降至约 297ms，单事件三格由约 745ms 降至约 323ms；这是合成输入与渲染回调测量，不等于整个画面停止。
- 第三阶段 63 项调度检查通过；第四阶段另有 21 项回归通过，五档 DPI/35 组尺寸检查通过，图标坞 25 组、历史滚动条 16 项检查通过。
- 30 条通知在固定布局的连续变形测试中，内容子树没有尺寸变化，末尾可达。离屏布局测试不代表整机帧率提升倍数。
- 尺寸弹簧余震、透明度中段和单格节奏仍待打磨；单格位置尾延迟约 229ms，尚未达到 200ms 目标。完整真实鼠标体验仍待最终验收。
- 构建保留原有 SQLite 原生依赖 NU1903 提示，本次未升级依赖。

## 下载与升级

下载 `DynamicIsland-v1.0.4-win-x64.zip`，先退出旧版本，完整解压后运行 `DynamicIsland.exe`。发布包内置 .NET 10 桌面运行时，无需另装 .NET；支持 Windows 10 19041+ / Windows 11 x64。原有用户配置保留。

`SHA256SUMS.txt` 提供 ZIP 的 SHA256 校验值。发布包不包含测试数据、日志或用户配置。
