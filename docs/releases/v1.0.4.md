# 灵动岛 DynamicIsland v1.0.4 · 最后一个构建版本

发布日期：2026-11-02。

**按用户要求，将已经完成的现有 Release 文件打包发布为最后一个构建版本；此后仅提供源码，不再提供新的预编译程序、安装包或构建 ZIP。** 本次未重新构建，也未运行新测试。

## 下载与启动

从 [v1.0.4 发布页](https://github.com/Charged-Cheese/windows-island/releases/tag/v1.0.4) 下载 `DynamicIsland-v1.0.4-final-win-x64.zip`，完整解压，退出旧实例后双击根目录的 **`启动灵动岛.cmd`**。这是唯一启动入口，不会自动构建。

系统要求：Windows 10 19041+ / Windows 11，x64；**需要已安装 .NET 10 桌面运行时（x64）**。本次沿用现有的框架依赖构建，未内置 .NET 运行时，不应套用 v1.0.3 的“无需安装运行时”说明。

包内保留程序依赖与托盘图标，包含许可证、使用说明及文件哈希清单；不包含用户设置、通知/剪贴板历史、日志、测试数据或 PDB。`SHA256SUMS.txt` 提供 ZIP 的 SHA-256。

## 更新内容

- 包含翻页第一至第六阶段：标准滚轮刻度累计、连滚追赶最新目标、六页固定布局与顶部锚定。
- 第五阶段尺寸定时通道：宽高和圆角独立 240ms，到期准确落位；支持反向、重定向、收起/通知接管及降低动效。
- 第六阶段透明度与节奏：指数 1.0、隐藏阈值 0.002；滚轮 k/c=1200/68；点击逐页 200ms Cubic，尺寸仍为 240ms。
- 同时包含六页界面、材质、通知保留设置与此前修复。完整记录见 [CHANGELOG](../../CHANGELOG.md)。
