## 0. 三条裁决（先把争议定死）

| # | 争议 | 裁决 | 理由 |
|---|---|---|---|
| 1 | 要不要"真·背景模糊" | **不做** | `AllowsTransparency=True` 是分层窗（MainWindow.xaml:7），DWM Acrylic/Mica 拿不到；`DwmSetWindowAttribute` 在 NativeMethods.cs:57 只有声明、零调用；BlurEffect 抓不到桌面且软件渲染逐帧重算；Mica 要求非 layered，等于重做窗口架构（圆角/外阴影全靠透明窗，xaml:7/116/136）。质感落成"透明度 / 层数 / 噪点 / 高光 / 阴影"的配方差异。 |
| 2 | 质感与主题怎样组合 | **正交：3 主题 × 4 材质 = 12，零复制** | 主题已是 14 色 record（ThemeManager.cs:10-24）+ Apply 写 12 资源（:116-127）。合并预设会让设置面板行数翻三倍（面板仅 452×700，SettingsWindow.xaml:5）。 |
| 3 | "全部重置"还是分层改造 | **分层改造** | 弹簧引擎（半隐式欧拉 + 0.004 子步 + 速度继承，IslandSpringEngine.cs:97-208）与玻璃四层是资产；推倒会回归 1.0.1「清透明度时钟 / 禁 Completed 复活」、1.0.3「固定六列 / 宽高双进度」。 |

**尺寸唯一真源**：窗口实为 600×470（MainWindow.xaml.cs:89-90），XAML 写 540×400（MainWindow.xaml:5），文档写 560×420。P0 统一为 600×470，并让 cs 常量成为唯一来源；README / 架构设计.md 同步。

## 2. 设计 token（样式的地基，P1）

### 2.1 字号：14 档 → 6 档

| token | 值 | 用途 |
|---|---|---|
| `FontMeta` | 9.5 | 页 meta、单位、补注 |
| `FontSmall` | 10.5 | 次要文字、艺人、标签 |
| `FontBody` | 11.5 | 正文、列表主行 |
| `FontTitle` | 13 | 页标题、媒体标题 |
| `FontLarge` | 15 | 大数值（温度、百分比） |
| `FontDisplay` | 17 | 日历日期、时钟 |

- 行高统一 1.35；时间/进度数字启用 tabular 数字（`Typography.NumeralAlignment="Tabular"`），避免宽度跳动。
- 字体：`Segoe UI Variable Text` → `Segoe UI` → `Microsoft YaHei UI`（Win11 光学尺寸更细腻，老系统自动回退）；图标保持 `Segoe Fluent Icons`。
- 现状 118 处显式 `FontFamily` 全部收进 `UiFont` 资源，不允许页面内再写字体名。

### 2.2 间距：54 种 Margin → 4 档

`4 / 8 / 12 / 14`：组内 4，元素间 8，组间 12，页面外距 14。列表行内边距 `10,8`。

### 2.3 圆角 4 档

`26`（岛）/ `14`（卡片）/ `10`（按钮、列表项）/ `8`（chip、图标底）。

### 2.4 颜色语义

- 保留 3 主题（曜石 / 石墨 / 瓷白）× 14 色 token。
- 新增语义色：`Success / Warn / Danger / Hover / Pressed / Overlay`。
- **必须修**：5 处硬编码 `#16FFFFFF` 等悬停色（App.xaml:79 等）在瓷白主题几乎不可见；瓷白下 Secondary `#99FFFFFF` 对 `#F5F7F8FA` 对比 <2:1，需按明暗两套值重出（目标 ≥4.5:1）。
- 高对比度兜底：读 `SystemParameters.HighContrast`，开启时强制不透明底 + 实边 + 系统色文字。

## 3. 质感（P2，设置里可选）

### 3.1 四档配方（只调 5 个参数，不新增布局）

| 档位 | 底 alpha | 噪点 | 顶部高光 | 内阴影 | 阴影 blur/depth |
|---|---|---|---|---|---|
| 清透 clear | 0.72 | 0 | 强 0.06 | 弱 | 28 / 10 |
| 玻璃 glass（默认） | 0.82 | 2.5% | 0.04 | 中 | 32 / 12 |
| 磨砂 frosted | 0.90 | 4.0% | 0.02 | 强 | 36 / 14 |
| 实色 solid | 0.97 | 0 | 无 | 无 | 24 / 8 |

- 明暗主题各一套基线，瓷白下"清透"自动提亮并换深色内阴影，避免发脏。
- 噪点用预生成 128×128 半透明 PNG 平铺（`ImageBrush TileMode=Tile`），零运行时成本。
- 实现：新增 `Infrastructure/MaterialManager.cs` + `Themes/Materials.xaml`；`AppSettings.Material` 与 `Theme` 并列（SettingsService.cs:98 旁）。
- 关键约束：`DropShadowEffect.BlurRadius`、`CornerRadius`、`GradientStop.Color` 不是依赖属性，只能代码写；Brush 必须沿用"每次发新冻结实例"（ThemeManager.cs:91-93、185-249），复用可变 Brush 会被 WPF 冻结抛错。
- 设置面板：外观区下方加 4 个 chip（复刻 SettingsWindow.xaml:174-209 行结构），点击立即 Apply，不重启。

### 3.2 阴影（卡顿根因之一）

现状岛体 `DropShadowEffect BlurRadius=40 ShadowDepth=16`（MainWindow.xaml:135-137），挂在**被每帧改变尺寸的 Border** 上 → 每帧重算高斯。

- 静止态：保留一层低 blur（≤28）。
- 动画态（弹簧未 settle）：Effect 置空，改用 3 层矢量柔边（不同 alpha 的圆角 Border）过渡，settle 后 1 帧交叉回真实阴影。
- 结果：动画期间无高斯重算，静止态保留深度。

## 4. 页面重排规则（P3 标杆页 → P4 全量）

### 4.1 全局密度规则（消解"极简 × 紧凑 × 信息量"三难）

1. 信息量 > 密度 > 留白装饰：不靠压 padding 换紧凑，靠**删重复标题、合并行、去内层卡**。
2. 留白只允许出现在内容组之间（12）与页面外缘（14），组内 4/8。
3. 每页限定条目数：天气 = 4 指标 + 3 日；硬件 = 2×3 卡；通知/剪贴板滚动 30/20 条。
4. 每页只保留一个主视觉焦点（媒体：封面+标题；硬件：进度环/条；日历：日期网格）。

### 4.2 媒体页（标杆页，384×188 → 目标）

- 媒体头 48+14 → **40+10**（现占页高 33%）。
- 内层卡：`CardSurfaceBrush` + 1px 边（xaml:476-478）**删除**，改"无填充 + 0.5px 极淡描边"——当前是 4 层玻璃 + 1 层卡片 = 5 层半透明白，是"糊"的来源。
- 控制钮 6 → 4：上一首 / 播放 / 下一首 / 静音常驻；**切源、日历入口收进右键菜单**，媒体头 hover 时补出切源（hove 才出现，默认干净）。
- 进度条：右侧改 **-剩余时间**；拖动时轨道 4→6px + 圆点外扩 + accent 光环 22%。
- 留白指标：内容包围盒 / 面板面积 ≤15%。

### 4.3 其余页要点

| 页 | 改动 |
|---|---|
| 天气 | 4 指标合一排；3 日预报行高 26；图标 16 |
| 硬件 | 6 条进度条 → **2×3 卡**（38 高 / r9 / 三段式：图标+标签+数值+底部 2.5px 条），<75% 强调色、≥75% 琥珀、≥90% 红 |
| 图标坞 | 六列保留，项 44→42，间距 8 |
| 通知 | 条目高 42，图标 28，改 `ListBox`+`VirtualizingStackPanel` 保虚拟化 |
| 歌词 | 三行行距 25；播放器 0.90；karaoke 200ms 重建画刷 → 60ms 步进 |
| 剪贴板 | 条目高 40，虚拟化同上 |
| 日历 | 460×320 保留；单元格 30；今日/选中态用语义色 |

## 5. 动画规格（P5，统一但不推倒引擎）

### 5.1 五条曲线 + 时长

| 场景 | 曲线 | 时长 |
|---|---|---|
| hover 进入/退出 | easeOutCubic | 120ms / 160ms |
| 按压 → 释放 | easeOutQuad → easeOutBack(1.05) | 90ms → 180ms |
| 页内容淡入 | easeOutCubic | 180ms |
| 通知卡进出 | easeOutCubic（scale 0.96→1、shift 8→0） | 260ms |
| 尺寸（弹簧） | 半隐式欧拉 | 展开 260–320ms / 收起 200–260ms，overshoot ≤2px |

- 弹簧参数：标准 520/34；Smooth ×1.0/×1.35；Bouncy ×1.1/×0.70；Snappy ×1.5/×1.25（现有档位保留，只统一标定）。
- 子步 4ms → **2ms**：掉帧时更稳，成本可接受。

### 5.2 状态机修正

- 页切换：8 页常驻 Visible 只改 Opacity（cs:2028-2079）→ 只让**当前页 + 相邻页**参与（其余 `Visibility=Collapsed`），消除每帧 8 份 opacity 中间层。
- 滚轮：每个 Wheel 直接改 ActiveTab（cs:1197-1219）→ **累积 + 120ms 闸门**，触控板 30+ evt/s 不再反复翻转。
- 跨页 >1：硬落位（cs:1941-1951）→ 两段式（淡出 90ms → 落位 → 淡入 150ms）。
- 通知复用早退（cs:664）→ 第二条通知也走完整进场动画。
- 隐私点 900ms Forever+AutoReverse（cs:380-391）→ 有设备时 1.6s 单次呼吸、静止即停（不再常驻满帧）。

### 5.3 每帧布局写（卡顿 P1）

| 位置 | 现状 | 改为 |
|---|---|---|
| HUD×3 | 每帧写 Margin（cs:1743-1760） | `TranslateTransform` |
| MorphCover | W/H + Margin（cs:278-305） | 尺寸 + Translate |
| 分页点 | Height（cs:2028-2079） | `ScaleTransform` |
| 频谱 | Height（cs:2287-2306） | `ScaleTransform` |
| 进度条 | 200ms 快定时器宽（VM:61） | 保留，但只在播放中跑 |

## 6. 鼠标互动（P4 末，零 XAML 改动方案）

现状：**0 个 Button**、47 处手写在 Border 上的点击、仅 5 处 hover 触发。逐个改 XAML 不现实。

**方案**：窗口级统一交互层（新文件 `Infrastructure/IslandInteraction.cs`）：
- `PreviewMouseMove`（节流 40ms）→ 从 `OriginalSource` 向上找 `Cursor==Hand` 的祖先 → 唯一 hover 目标，做 120ms 补间（背景 alpha + 1px 上移 + 1.02 缩放）。
- `PreviewMouseDown/Up` → press 0.97 缩放 90ms，释放回弹 180ms。
- 同时刻最多 **1 个** hover 过渡（防动画时钟爆炸反掉帧）。
- 不做点击涟漪（软件渲染多一层半透明合成，收益低）。
- 数据卡 / 纯展示行**不加**装饰性互动（违反极简）。

验收：hover 视觉反馈 ≤1 帧；点击到视觉反馈 ≤50ms。

## 8. 验收指标（必须可测，否则不算完成）

1. 展开 260–320ms、收起 200–260ms，overshoot ≤2px（标准档）。
2. 帧 p95 ≤16.7ms；切页/滚动 99 分位无 >33ms 帧；>20ms 帧占比 <2%。
3. hover 反馈 ≤1 帧；点击到视觉反馈 ≤50ms。
4. 常驻内存增量 ≤+20MB（基线约 183MB），反复切主题/材质不累积。
5. 每页空白率 ≤15%；字号 ≤6 档；折叠态宽 ≤204。
6. 瓷白主题下次要文字对比 ≥4.5:1；高对比度模式下全部可读。

- **字号收敛到 6 档**：涉及 8 页 + 3 个 HUD 的上百处 `FontSize`，收益低于回归风险，留作后续单独一阶段。
- **抽页头模板**：`tools/LauncherLayout.SelfTest` 与 `HistoryScrollbars.SelfTest` 直接解析 `MainWindow.xaml`，抽模板会让 41 项自检静默失效，需要先改自检再动模板。
