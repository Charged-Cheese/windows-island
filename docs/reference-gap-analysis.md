## 结论

调研文档第 4 节的 12 项借鉴清单**全部已落地**（主题、分页点、剩余时间、交叉淡入、morph、取色、硬件卡、动画预设、nudge、媒体卡、karaoke、材质降级）。今天仍然存在的差距集中在四处：**材质里的强调色 bloom 层、弹簧积分子步、空闲渲染频率、少数动效细节**。大多是小改动，不是结构性差距。

## 建议的动手顺序

1. **A1 弹簧 1ms 子步**（十几行，直接影响"丝滑"的下限）
2. **I1 控件热区 +6px**（纯 XAML，手感立刻好转）
3. **V1 强调色 bloom 层**（视觉提升最明显，和封面取色联动）
4. **P1 空闲节流**（省电，同时让帧数据更好看）
5. **V2 主题扩到 6–8 套**（低成本，用户可选择面变大）
6. **V5 硬件页加网络卡**、**V4 字号 token**、**A3 缩放 0.965**、**A4 换歌过渡**

明确不做：V3 七层阴影、V6 封面放大到 64、P4 自选刷新率、以及"改成 Direct2D 自绘"这条路线（WPF 合成特性不同，重写等于重做项目）。

## 已落地（2026-10-31）

用户选定 V1 / V4 / A1 / A4 / P1 / I1 六项，全部实现：

| 项 | 实现 |
| --- | --- |
| V1 强调色 bloom | 岛体新增独立光晕层（`AccentBloomBrush`），`RadialGradientBrush` 圆心压在底部中段 (0.5, 0.96)，媒体页强度 0.12、其他页 0.07；跟 `AccentBrush` 一起重发，换歌取色过渡时一起渐变。不参与命中测试。 |
| V4 字号阶梯 | `App.xaml` 定义六档 token（Sm/Base/Md/Lg/Xl/Xxl = 9.5/10.5/11.5/13/15/17），`MainWindow.xaml` 里 114 处散落 FontSize 归并进来；图标字号 7.5/8 与超大号 22/26/31 保持硬编码。 |
| A1 弹簧子步 | `IslandSpringEngine.OnRendering` 子步 4ms → 1ms，高刚度档（干脆 450）收尾更干净。 |
| A4 换歌过渡 | 封面独立 `CoverSwap` ScaleTransform 收缩到 0.86 再弹回（260ms），控制区 200ms 淡入，标题位移与淡入保留；不做 3D 翻转。 |
| P1 空闲节流 | 标题跑马灯 `Timeline.SetDesiredFrameRate(40)`、隐私点脉冲 30fps；折叠静置从 180fps 降到 ≈56fps（16 秒 900 帧）。 |
| I1 热区 | 媒体头 6 个按钮改「外层 26×26 命中层 + 内层视觉」，负外边距抵消占位，按钮组总宽不变；实测点在内层视觉外 3px 仍命中。 |

明确不做的三项：V3 七层阴影（WPF 每层一次高斯，软件渲染下代价高）、V6 封面 64（会挤掉标题宽度）、V2 扩到 8 套主题（现有 3 主题 × 4 材质已覆盖场景，扩主题只是维护成本）。
